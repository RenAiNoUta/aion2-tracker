# Aion2 Reset Tracker

**▶ Open the tracker: https://renainouta.github.io/aion2-tracker/**

Daily and weekly checklist for Aion2 Global, with reset countdowns, reminders, entry item levels, a gear route to 3,000 iL and boss cheatsheets for Conquest and Transcendence.

- Resets: daily 07:00 UTC, weekly Wednesday 07:00 UTC.
- Progress is saved in your own browser; nobody else sees it.

The whole app is a single file, `index.html`.
